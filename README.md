# Bloom & Beyond

Premium website for **Bloom & Beyond** — a luxury gifting, decoration, and surprise experience brand.

> Beautiful Moments, Made with Love.

![Bloom & Beyond](./public/images/logo.jpg)

## Overview

Bloom & Beyond helps people create unforgettable moments for birthdays, anniversaries, proposals, graduations, baby showers, apologies, and more.

This project is a modern, responsive marketing website with interactive planning tools — not an e-commerce store.

## Features

- Full-bleed luxury homepage with brand-focused hero
- Services, occasions, testimonials, and masonry gallery
- **Find Your Perfect Surprise** — multi-step recommendation quiz
- **Gift Inspiration** — searchable, filterable idea gallery
- **Send a Surprise Request** — validated inquiry form with WhatsApp handoff
- **Love Calendar** — save important dates in local storage
- Floating WhatsApp button and sticky navigation
- Dark mode support
- Smooth Framer Motion animations
- SEO metadata and accessibility-friendly structure

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Getting Started

### Prerequisites

- Node.js 18+ recommended
- npm

### Install

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

> Note: Because this project folder name contains `&`, the npm scripts call Next.js through Node directly for Windows compatibility.

### Production build

```bash
npm run build
npm start
```

## Project Structure

```text
src/
  app/                 # Next.js app routes & global styles
  components/          # UI sections and feature components
  data/                # Content and feature data
  lib/                 # Helpers (storage, theme)
public/
  images/              # Optimized website images
  videos/              # Gallery videos
pictures/              # Original media source files
```
